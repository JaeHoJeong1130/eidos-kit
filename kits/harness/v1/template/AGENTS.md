# Example Project agent bootstrap

For explanation or inspection without writes, select `read-only` (R0) and start with the requested
source and evidence. No Work, claim, change verification, or requirements command is required.
Read relevant contracts and Failure entries when the question depends on them or tool side effects
are unclear. Preserve files and the Git index. Follow project privacy and domain rules; do not store
credentials, personal data, raw chat or logs. Never infer remote or unpushed work or external authority.

Before any change, including a query that becomes an edit, read `.agents/context.json`,
`.agents/routing.md`, and `.agents/harness/contract.md`. Select exactly one applicable route and
only its rubrics and relevant failures; follow `.agents/workflows/change.md` and applicable domain
requirements. When Eidos is enabled, use Direction for strategy, Work for execution, and derived
focus for current activity; read them when starting, resuming, or redirecting work.

Project-specific additions may be appended below this line. Kit upgrades never overwrite this file.
